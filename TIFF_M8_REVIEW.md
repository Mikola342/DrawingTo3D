Основной источник — TIFF. Проверяемая база: `CadTest/output/tiff-revision/1751736db163482782bb2b44904205d8/Tsapfa_TIFF_II_CHANNEL_WIP.SLDPRT`, SHA256 `4F592E305EA5AA290E8AF6FED3FFEE154EA04B0BFF8DC74364EA5665DFF4ED75`.

## Причина первоначального отказа

Старая проверка `Feature.GetFaces()` учитывала все плоские грани операции как грани собственно резьбы. Для нового узла она получила минимальный радиус0,08985 мм на плоской грани и отклонила результат. Эта попытка не была сохранена как принятая модель.

Добавлена независимая проверка разности тел: копия тела после цилиндрического пилота минус тело после M8. Для изолированных тел снятого материала используется `IBody2.GetEdges()` — [документация SolidWorks](https://help.solidworks.com/2026/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IBody2~GetEdges.html).

Диагностический запуск `CadTest/output/tiff-m8-diagnostic-20260928_005116.log`:

- Два тела снятого материала, 2145 точек на рёбрах.
- Радиальные пределы3,323417653…3,999999997 мм.
- Осевые пределы0…6,092559671 мм.
- Изолированный объём37,095227328 мм³; разность объёмов всей детали37,099138635 мм³. Расхождение0,003911307 мм³ укладывается в проверочный порог0,01 мм³; это не допуск изготовления.

Контроль плоских граней уточнён только для TIFF M8 и только после успешной проверки разности тел. По-прежнему проверяются общие осевые границы, максимальный радиус, минимальный радиус неплоских граней и сохранённые параметры резьбы. Проверки старых M8 по умолчанию не ослаблены.

Для повторной проверки с диска M8 временно подавляется в отдельной проверочной копии, снимается копия тела, затем M8 восстанавливается в `finally`; проверяются восстановленный объём и разность тел. Исходный файл не пересохраняется.

## Ограничения

Это номинальный библиотечный профиль M8×1,25, не подтверждение поля допуска6H. Рабочий осевой интервал X254…260 и длина6/cos10 пока унаследованы от эксперимента; отдельный размер длины резьбы на TIFF не установлен. Выборка рёбер — не доказательство точных экстремумов всех поверхностей. Корпус остаётся переходным между PDF и TIFF; см. `TIFF_BODY_DATUM_REVIEW.md`.
