## Реализованные изменения после старого контекста

### Правый конец внутренней расточки

В `Program.cs` добавлено:

```csharp
BoreEndWallThickness = 8,
```

В `PartDescription.ValidateRevolveProfiles()` добавлена проверка, что конец `BoreRevolveProfile` оставляет заданную толщину правой стенки.

### Дуги наружного профиля

`RevolveProfileElement` теперь содержит `Radius`.

`SolidWorksService.CreateRevolveSketchFromElements()` умеет строить `RevolveProfileElementType.Arc` через `Create3PointArc()`. Валидация проверяет, что обе конечные точки дуги лежат на её радиусе.

Пока в наружном профиле дуги не используются: R35/R50 не вводить до точного восстановления их конечных точек из чертежа.

### Наружная резьба M90×2

В `Program.cs` добавлено описание:

```csharp
Threads = new List<ThreadDescription>
{
    new ThreadDescription
    {
        Type = ThreadType.External,
        Designation = "M90x2",
        ToleranceClass = "6g",
        NominalDiameter = 90,
        Pitch = 2,
        StartPosition = 0,
        Length = 3
    }
},
```

В `SolidWorksService` добавлен метод `CreateLeftExternalThread(ThreadDescription)`. Он выбирает круговую кромку левого торца Ø90 лучом вдоль +X и создаёт Thread Feature с профилем `Metric Die.SLDLFP`.

Вызов выполняется сразу после основного Revolve и до внутренней расточки:

```csharp
solidWorks.CreateRevolveFromDescription(part);
solidWorks.CreateLeftExternalThread(part.Threads.Single());
solidWorks.CreateBoreRevolveProfile(part);
```

### Защита типов резьбы

`CreateThreadFromDescription(HoleDescription)` теперь явно принимает только `ThreadType.Internal`. Это не даёт случайно применить профиль `Metric Tap.SLDLFP` к наружной резьбе. Для M90 используется отдельный проверенный метод `CreateLeftExternalThread(ThreadDescription)` с профилем `Metric Die.SLDLFP`.

## Важные API-особенности

- Используется typed Interop, не `dynamic`.
- Стандартная плоскость: `Спереди`.
- Ось вращения: `Line1@<имя эскиза>`, mark 4.
- `ModelDoc2.FeatureByName()` в используемой версии Interop отсутствует; feature искать перебором `FirstFeature()` / `GetNextFeature()`.
- `CreateArc()` оказался ненадёжным для малых дуг; использовать `Create3PointArc()`.
- Текущий метод `CreateThreadFromDescription(HoleDescription)` рассчитан на внутренние резьбовые отверстия. Для наружной левой M90 добавлен отдельный проверенный метод. Не использовать этот метод для M8/M12/M18 без точной реализации выбора их кромок.

## Текущий временный наружный профиль

`RevolveProfile` пока контрольный, а не финальный по чертежу. Он обеспечивает материал для проверки API, но не должен считаться соответствующим всем наружным диаметрам/переходам детали.

## Следующий безопасный порядок работ

1. По продольному разрезу окончательно восстановить наружный профиль, начиная с участка около левого R35 и с подтверждёнными осевыми цепями.
2. После каждого небольшого изменения выполнять `dotnet run`, проверять полный лог и новый `Test_*.SLDPRT`.
3. Отдельно реализовать выбор стартовых кромок для M8×1,25-6H, M18×1,25-6H и двух M12-7H, только после подтверждения их координат, направлений и базовых отверстий. Не добавлять эти резьбы через `CreateThreadFromDescription`, пока отверстия не созданы на точных гранях.
4. Добавить оставшиеся фаски, радиусы и локальные элементы.
5. Выполнить финальную проверку модели по чертежу.
