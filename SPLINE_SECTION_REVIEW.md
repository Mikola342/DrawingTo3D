# Шлицы: проверенный поперечный профиль, без выреза в CAD

Уточнение корня: `SPLINE_ROOT_REVIEW.md`. Синие кривые SVG теперь ограничены Ø95..100; продолжение до Ø94 выделено оранжевым пунктиром как неподтверждённое. `spline-root-study.json` содержит НЕ выбранные круговые варианты сопряжения. R=0,47m из таблицы ГОСТ нельзя автоматически считать радиусом готового корня.

Осевые ограничения теперь рассчитаны отдельно: `SPLINE_AXIAL_REVIEW.md`, `CadTest/output/spline-axial-study.json`. Команда `--audit-spline` формирует оба исследования; найденный след R50 не является готовой поверхностью трёхмерного выреза.

Обновление stage15: построен заход заготовки 15° при X=42, см. `SPLINE_LEAD_STAGE15.md`. Сами зубья, корневые переходы и выход R50 остаются незавершёнными.

Обновление stage14: наружный переход к Ø105 (R3/30°) построен отдельно, см. `SPLINE_SHOULDER_STAGE14.md`. Это не инструментальный выход R50 и не шлицевые зубья; перечень задач ниже следует читать с этим уточнением.

Источник размеров детали: вид В-В и обозначение Эв. 100×2,5×38 на `chertezh_corrected_final.pdf`.
Источник формул: [скан официального переиздания ГОСТ 6033-51, таблица 1, стр. 3](https://files.stroyinf.ru/Data/273/27388.pdf). Страница просмотрена визуально; формулы не взяты из ошибочного OCR.

Для D=100, m=2,5, z=38: делительный диаметр 95 мм, угол профиля 30°, смещение рейки 1,25 мм. Основной диаметр равен 95·cos30°=82,27241336 мм. Толщина зуба по делительной окружности πm/2+2x·tan30°=5,37036649 мм; это согласуется с номинальным 5,37 на чертеже. Номинальный диаметр плоской впадины D−2,4m=94 мм также совпадает с видом В-В.

Важно: 5,37 — не ширина вершины и не произвольный прямоугольный зуб. По отклонениям −0,035/−0,038 на чертеже диапазон толщины 5,332..5,335 мм. В исследовательской схеме выбран его центр 5,3335, но CAD-зубья по нему ещё не построены. Чисто нормативные 5,37036649 не должны автоматически стать толщиной готовой детали вне этого диапазона.

`SplineSectionStudy` вычисляет эвольвентные боковые поверхности. Проверяются делительная толщина, монотонное сужение зуба, отсутствие наложения соседей, 1001 радиальное сечение и запрет вычисления ниже основной окружности. Формула половины угловой толщины: S/d + inv(30°) − inv(acos(rb/r)).

```powershell
dotnet run --project CadTest -- --audit-spline
```

Выходы: `CadTest/output/spline-section-study.json` и `spline-section-study.svg`. SVG показывает только 76 эвольвентных боковых кривых; он НЕ замкнутый контур для изготовления. Осевые границы, R50/R3, инструментальные корневые переходы и угловая фаза относительно местных вырезов остаются задачами перед переносом в CAD. Прямоугольные пазы вместо эвольвент не добавлялись. Схема просмотрена после рендеринга.
