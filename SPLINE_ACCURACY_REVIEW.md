# Проверка эвольвентных CAD-кривых

Команда: `dotnet run --project CadTest -- --check-spline-accuracy <пробный.SLDPRT>`.

Проверка читает эскиз операции `TRIAL_38_spaces_to_X70_RootApprox` из открытого документа SolidWorks. Из эскиза извлекаются лежащие в основе сегментов CAD-кривые, а не ранее сохранённые массивы исходных точек. Для каждой из 76 эвольвентных сторон вычисляются 129 точек на полном параметрическом интервале кривой. Считается расстояние по хорде между CAD-точкой и точкой расчётной эвольвенты на том же радиусе.

Дополнительно проверяются диапазон радиусов 47,5..50 мм и оба конца, плоскостность, постоянная принадлежность стороне впадины, отсутствие дублирующихся сторон и полное покрытие 38 пар. Внутренний порог выборочного отклонения 0,0001 мм (0,1 мкм) не является допуском чертежа или обещанием точности изготовления.

Читается CAD-эскиз прямого выреза. Проверка НЕ измеряет каждую точку обрезанных поверхностей тела, НЕ проверяет отдельные эскизы 38 дисковых выходов и НЕ даёт строгую верхнюю оценку погрешности между отсчётами. Неопределённость формы инструмента и угловой фазы сохраняется. Исходный SLDPRT не пересохраняется; JSON создаётся только после успешных проверок. Уже открытый документ проверяется в памяти, это не независимая повторная загрузка с диска.

Код: `CadTest/Cad/SplineAccuracy.cs`. Используются [ISketchSegment.GetCurve](https://help.solidworks.com/2015/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.ISketchSegment~GetCurve.html) и [ICurve.GetEndParams](https://help.solidworks.com/2014/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.ICurve~GetEndParams.html) для чтения кривой и её параметрического диапазона.

## Результат

Проверен `Tsapfa_TRIAL_Splines_RootApprox_R50Disk_20260924_183038_883.SLDPRT`: 76 кривых, 9804 отсчёта, все проверки пройдены. Максимальное выборочное отклонение 1,168292112·10⁻⁹ мм — численное совпадение в этой проверке; настолько малое значение нельзя трактовать как физическую точность детали. В отчёте сохранены результаты отдельно для каждой стороны.

Отчёт: `CadTest/output/Tsapfa_TRIAL_Splines_RootApprox_R50Disk_20260924_183038_883_accuracy_20260924_154703_254.json`. Журнал `spline-accuracy.log`; stderr пуст. Перед проверкой пройдены прежние 61 отрицательный сценарий и расчётные исследования. Сборка без ошибок, с прежним предупреждением CA1416 о Windows COM. CAD-геометрия и SLDPRT не изменены.
