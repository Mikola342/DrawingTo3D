# Stage8: объединённый блок наружных сопряжений

Источник: `CadTest/chertezh_corrected_final.pdf`, разрез А-А. Дата: 24.09.2026.

## Изменения геометрии

1. Вход Ø105 в конус 30°: R2 min принят равным 2 мм. Теоретический острый угол X=178,669872981 сохранён как размерная привязка, а не точка касания. Начало дуги X=178,133974596/R52,5; центр X=178,133974596/R54,5; конец X=179,133974596/R52,767949192. Далее та же прямая 30° до X=183/R55.
2. Правый конец Ø125: номинальный R2 по выноске R2±0,2. Начало X=237/R62,5, центр X=237/R64,5, конец X=239/R64,5. Выше остаётся предварительная оболочка, а не восстановленные ступени Ø131/164/188.
3. Сохранены R2 у X=215 и переход длиной 3 мм / 30°, построенные в stage7. Все три дуги вращаются как точные окружности.

## Проверки

- Добавлены проверки принадлежности концов окружности, касания соседних отрезков, направления касания и конечности координат центра.
- Тесты выбирают изменившиеся элементы по геометрическим признакам; исправлена неоднозначность выбора цилиндра Ø125 после добавления дуги.
- Валидная модель и 33 отрицательных сценария проходят `dotnet run --project CadTest -- --self-test`.
- Объём: 2 187 312,738589 мм³. Изменение относительно stage7: +347,628119 мм³.
- Независимая проверка нового конусного сопряжения использует численное интегрирование по X, не угловую первообразную рабочего расчёта. Для правого четвертькруга используется отдельная формула.
- При CAD-проверке требуются одно тело, ожидаемые круговые рёбра, цилиндры, все три наружных тора R2, тор канавки R0,5, отверстия, совпадение объёма и отсутствие ошибок операций.

## Границы результата

Это проверка реализованной геометрии, не доказательство полного соответствия детали чертежу. Д/К, ступени X=239..247, левая часть, резьбы и боковые каналы остаются незавершёнными. Выбор R2 на нижней границе R2 min явно отражён в параметрах; торец воротника по-прежнему выбран с нулевым отступом.

Выходные данные: `CadTest/output/stage8-description.json`, `stage8-section.svg`, `stage8-collar-detail.svg`. SVG является параметрической схемой, не экспортом CAD, и не показывает местное Ø12.
Журнал CAD: `CadTest/output/stage8-build.log`, ошибки: `stage8-build.err.log`.
