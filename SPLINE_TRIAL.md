# Согласованный пробный профиль шлицев

Последующее построение: профиль перенесён на отдельную полную цапфу с экспериментальными выходами R50, см. `SPLINE_TRANSFER_TRIAL.md`. Ниже описан исходный контрольный образец 20 мм, который сохранён отдельно.

Пользователь согласовал отдельный пробный вариант с круговым корнем R≈1,016 мм. Это разрешение на явно обозначенное упрощение, а не подтверждение соответствия изготовленному корню по чертежу.

## Область пробного построения

Первое 3D-построение — самостоятельный контрольный участок постоянного сечения длиной 20 мм, не полная цапфа. Основная stage15 не изменяется. Ось образца — Z; рабочая осевая привязка и фаза относительно элементов цапфы не назначаются. R50, заход 15° и местный вырез R35 в образце отсутствуют. Образец проверяет только замыкание и 3D-построение поперечного профиля.

38 зубьев, модуль 2,5, угол профиля 30°, номинальные Ø100/Ø94, канал Ø62. Толщина зуба по делительной окружности 5,3335 мм — исследовательская середина ранее прочитанного диапазона. Круговой корень R=1,0161290322580643 мм касается эвольвенты при Ø95 и корневой окружности Ø94.

На один шаг приходится шесть участков: корневая дуга, скругление, эвольвентная сторона, дуга вершины, вторая сторона и второе скругление. Всего 228 участков. В CAD дуги строятся как окружности, каждая эвольвента — интерполяционный сплайн по 33 точкам. Это приближение эвольвенты, не аналитическая CAD-кривая; поперечная погрешность между узлами ещё не аттестована.

## Проверки и запуск

`dotnet run --project CadTest -- --test-trial-spline` проверяет замыкание контура, радиальные границы, монотонность полярного обхода, касательность корней и сходимость численного интеграла площади. Расчётный объём 20-мм образца: 88043,053259 мм³.

`dotnet run --project CadTest -- --trial-spline` создаёт НОВЫЙ документ SolidWorks. Приёмка: одно тело, 38 цилиндрических вершин, 38 корневых участков, 76 корневых скруглений и канал, а также совпадение объёма с расчётом в пределах 0,1 мм³. Сохранение идёт только после этих проверок в отдельный `Spline_TRIAL_RootApprox_20mm_*.SLDPRT`, рядом JSON с ограничениями. Это не общий отчёт приёмки цапфы.

Используемый API интерполяции: https://help.solidworks.com/2018/english/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.ISketchManager~CreateSpline2.html.

Сохранён `CadTest/output/Spline_TRIAL_RootApprox_20mm_20260924_181843_469.SLDPRT`, рядом одноимённый JSON. CAD-проверки пройдены: одно тело, все ожидаемые цилиндрические участки. Объём CAD 88043,054546 мм³ против расчётного 88043,053259 мм³; разность около 0,001287 мм³ при пределе 0,1 мм³. Журнал `spline-trial-build.log`, stderr пуст.

Построение образца подтверждает реализуемость выбранного замкнутого поперечного профиля в SolidWorks. Оно не подтверждает точность формы относительно инструмента, работу соединения или готовность всей цапфы.
