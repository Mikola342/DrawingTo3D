# Перенос начала расточки Ø68 на X181

Основной источник — TIFF5309-2304083, разрез А–А. Номинальная цепь:265−84=181 мм. Предыдущая модель имела начало на X203,5. Изменяется только участок181…203,5; задняя часть расточки, Л и остальные неподтверждённые узлы не считаются исправленными этим действием.

## Метод

Из проверенной модели с M8 (SHA256 `3718440ACD31E6CC221C1E8C3ADC0DEBD713BA4E73860E01039F2234B1EE26E4`) создаётся отдельная копия. Добавляется цилиндрический вырез Ø68 длиной22,5 мм. Исторические операции не подавляются и не удаляются. Обязательны:

- Начальный контроль сохранённого Ø68: X203,5…240.
- После изменения: соосный цилиндр Ø68 начинается на X181; конец X240 пока исторический, не принят по TIFF.
- Объём снятого материала сверяется с кольцом R31…34 минус пересечение с каналом И–И10°.
- Сохраняются исходные состояния подавления всех унаследованных операций; нет ошибок/предупреждений активных операций.
- Проверяются соединения И–И с центральной расточкой и Ø6,8.
- После сохранения — свежая проверочная копия, повторный контроль Ø68, канала, M8 и объёма; неизменность файлов по SHA256.

Расчёт:13783,695304478 мм³, разница между сетками400×400 и800×800 —0,000027191 мм³. Контрольный порог расхождения CAD/расчёт0,02 мм³ — порог численной проверки, не производственный допуск. Сечение наклонного канала учтено эллипсом, не кругом. Код `TiffBoreStudy.cs` включён в `--self-test`.

## Ограничения

Модель номинальная: поле допуска Ø68 и скругление R1max у нового уступа не приняты. Полный профиль расточки по TIFF ещё не восстановлен; исправление одной базы не подтверждает корпус целиком. Запуск `--rebuild-tiff-bore-start` разрешён программой только для указанной проверенной исходной модели.

Соединения И–И сохранились. Ошибок/предупреждений активных операций после изменения нет; состояния подавления прежних операций сохранены. Рядом JSON и просмотренное изображение.

Первая повторная загрузка из вложенного пути длиной277 символов завершилась `errors=2`. Проверочная копия тех же байтов из короткого `CadTest/output/tiff-verification/...` открылась без предупреждений; это указывает на ограничение пути. Проверки теперь создаются в этой короткой папке.

Повторный контроль с диска **пройден**. Отчёт: `CadTest/output/tiff-verification/a5024035636d4b2a96f0cd758e40b1ce/verification.json`. Подтверждены Ø68 от X181 до X240 (99 точек), ось10° и соединения И–И, номинальная M8 (1122 точки граней и2145 точек снятого материала), объём2022713,058221454 мм³. Исходный файл, проверочная копия и JSON построения остались побайтно неизменными. SHA256 новой модели `55F365670E96C126A053A4F1AD810BCF76F97126B75784FD72188E7D86C7E708`.

Это целевая проверка исправленного участка и связанных узлов, не полная повторная приёмка всех элементов детали по TIFF. Конец Ø68 наX240 по-прежнему исторический; проверка его сохранности не подтверждает его соответствие TIFF.
